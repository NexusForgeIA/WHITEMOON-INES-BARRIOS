Política de privacidad de esta demo

Esta web es una demostración creada por WhiteMoon (whitemoon.es) para Inés Barrios Reformas e Interiorismo. El responsable de los datos que se recogen aquí es WhiteMoon.

El chat de Ana es un asistente virtual guiado por botones. Si lo completas, recoge tu nombre, tu teléfono, el tipo de obra que te interesa, la localidad de la vivienda, cuándo te gustaría empezar y tu preferencia de contacto (mañana o tarde). La web no recoge ningún otro dato y no usa cookies ni analítica.

La única finalidad es devolverte el contacto sobre esta demo. Los datos se guardan en la base de datos de WhiteMoon (Supabase) y se envían como aviso interno por Telegram. No se usan para publicidad ni se ceden a terceros.

Puedes pedir que borremos tus datos escribiendo a comercial@whitemoon.es.
